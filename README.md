## 🚀 Free Hosting Options (100% Free Forever)

### Option 1: GitHub Pages (Recommended)
Since you already have a GitHub account (`bhargavreddy-12`), GitHub Pages gives you a clean, free URL:
`https://bhargavreddy-12.github.io/portfolio/`

#### Step-by-Step:
1. Open your browser and go to [https://github.com/new](https://github.com/new).
2. Name the repository: `portfolio` (leave it Public).
3. Do **NOT** initialize with README (we already have all files ready). Click **Create repository**.
4. Open PowerShell in `c:\Users\venky\Downloads\bhargava-portfolio\bhargava-portfolio` and run:
   ```bash
   git branch -M main
   git remote add origin https://github.com/bhargavreddy-12/portfolio.git
   git push -u origin main
   ```
5. On your GitHub repository page:
   - Click **Settings** (top tab) → **Pages** (left sidebar).
   - Under **Build and deployment → Branch**, choose `main` and folder `/ (root)`.
   - Click **Save**.
6. Within 1-2 minutes, your website will be live at:
   👉 **`https://bhargavreddy-12.github.io/portfolio/`**

### Option 2: Netlify Drop (Instant, No Command Line)
Deploy in 30 seconds without touching Git or terminal:
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop) (sign in or create a free account).
2. Drag and drop the folder `bhargava-portfolio` directly onto the web page.
3. Netlify will immediately deploy your site and provide a free live URL (e.g. `https://bhargava-portfolio.netlify.app`) with free SSL.
4. You can customize the subdomain anytime in Site settings.

---

### Option 3: Vercel (Fast Global CDN)
1. Go to [https://vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **Add New** → **Project**.
3. Select your `portfolio` repository and click **Deploy**.
4. Vercel automatically deploys the website to a free `*.vercel.app` URL with automatic SSL.
